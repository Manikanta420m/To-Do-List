# 📝 React To-Do List

A simple and interactive **To-Do List** application built with **React.js** that allows users to manage their daily tasks efficiently. Users can add new tasks, delete completed tasks, and rearrange tasks using move up and move down buttons.

## 🚀 Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ⬆️ Move tasks up
- ⬇️ Move tasks down
- ⚛️ Built using React Hooks (`useState`)
- 🎨 Clean and responsive UI
- ⚡ Instant updates without page refresh

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/react-todo-list.git
```

2. Navigate to the project folder

```bash
cd react-todo-list
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open your browser and visit

```
http://localhost:5173
```

## 💻 How It Works

- Enter a task in the input field.
- Click the **Add** button to add it to the list.
- Click **Delete** to remove a task.
- Click **⬆️** to move a task upward.
- Click **⬇️** to move a task downward.
